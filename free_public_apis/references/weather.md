# Weather APIs

This file contains free, No-Auth, HTTPS APIs for this category.

| API Name | Description | Documentation URL | Example GET Endpoint |
|---|---|---|---|
| AviationWeather | NOAA aviation weather forecasts and observations | https://www.aviationweather.gov/dataserver | `https://aviationweather.gov/cgi-bin/data/metar.php?ids=KORD&format=json` |
| Hong Kong Obervatory | Provide weather information, earthquake information, and climate data | https://www.hko.gov.hk/en/abouthko/opendata_intro.htm | `https://data.weather.gov.hk/weatherAPI/opendata/weather.php?dataType=flw&lang=en` |
| MetaWeather | Weather | https://www.metaweather.com/api/ | `https://www.metaweather.com/api/location/search/?query=san` |
| Open-Meteo | Global weather forecast API for non-commercial use | https://open-meteo.com/ | `https://api.open-meteo.com/v1/forecast?latitude=52.52&longitude=13.41&current_weather=true` |
| openSenseMap | Data from Personal Weather Stations called senseBoxes | https://api.opensensemap.org/ | `https://api.opensensemap.org/boxes` |
| RainViewer | Radar data collected from different websites across the Internet | https://www.rainviewer.com/api.html | `https://api.rainviewer.com/public/weather-maps.json` |
| US Weather | US National Weather Service | https://www.weather.gov/documentation/services-web-api | `https://api.weather.gov/points/39.7456,-97.0892` |
| weather-api | A RESTful free API to check the weather | https://github.com/robertoduessmann/weather-api | `https://goweather.herokuapp.com/weather/Curitiba` |
